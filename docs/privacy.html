Privacy policy

Effective October 7, 2026

JEV Mod is a Discord bot that moderates messages in the servers that add it. This policy explains what it reads, what it keeps, who it shares data with, and how to get data deleted.

What the bot reads

In the channels it can see, JEV Mod reads every new or edited message from members who aren't exempt. The server owner, members with the Manage Messages permission, bots, and any roles or channels the server exempts are not checked. For each checked message it uses:

  • the message text, and the message it replies to, if any;
  • the author's Discord user ID and username;
  • up to five earlier messages in the same channel, with their authors' usernames, so a message is judged in context;
  • the author's own messages from the last 30 minutes, to spot spam and patterns such as bullying.

What is sent to other companies

To decide whether a message breaks the rules, the bot sends the information above, along with the server's own rules, to TypeSafe AI, which runs the Jev model. If the bot's operator configures Anthropic's Claude instead, it is sent to Anthropic. These providers process it under their own terms and privacy policies. We don't sell data or share it with anyone else, and we don't use it for advertising.

Messages caught by the built-in spam and scam checks are not sent. With Jev, very short or simple messages (such as "gg" or emoji) and text judged clean within the last hour are not sent either.

When JEV Mod is removed from a server, that server's offense records and settings are deleted.

What is posted in your server

When the bot acts, it DMs the member the reason and their punishment, posts a short notice in the channel that deletes itself after 15 seconds, and, if the server set a mod log channel, posts the details there, including the message text (up to 1,000 characters). Those mod log posts are ordinary Discord messages that the server's staff control.

Your choices

  • Server staff can see a member's records with /strikes and delete them with /pardon.
  • Server admins can remove the bot at any time, which deletes the server's data.
  • Anyone can ask for their data to be deleted, or ask what's held about them, by opening an issue. Please don't post personal details there. Say you'd like to be contacted privately.

Children

JEV Mod is only for use on Discord, which requires users to be at least 13 (or older where local law requires it).

Changes

If this policy changes, the updated version will be posted here with a new effective date.

Jef Bot documentation

Jef Bot is hosted AI chat moderation for Discord servers, game chat and any app that can make an HTTP request. Jev, TypeSafe's decision model, does the judging; Jef Bot keeps the rules, strikes, punishments and history.

Game chat quickstart

Moderate your game's chat from your game server with one API call per message.

Discord quickstart

Add the Jef Bot bot to your server and link it to your account.

Give a coding agent an account key and let it set everything up over the API.

Every /v1 endpoint, its fields and errors. Also as OpenAPI 3.1.

Concepts

Account

You sign in with Google at /app/login; that creates your account. An account has a plan (Free, Starter or Pro, see pricing) that sets its limits, and counts its usage per calendar month (UTC): messages moderated and AI checks used, across all its apps.

Apps

An app is one community being moderated. Each app has its own custom rules, strikes, history and settings. There are two kinds:

KindForHow messages get checked
discordOne Discord serverThe Jef Bot bot reads the server's messages and carries out the punishment itself: deletes the message, DMs the member, times them out or bans them, and posts to your mod log.
apiA game, a website, any chatYour server sends each message to POST /v1/moderate and gets a verdict back. Your code removes the message and mutes or bans the player.

A Discord server can be linked to only one app at a time. One app can't cover several Discord servers; create one app per server.

If an account has more apps than its plan allows (after a downgrade), only the oldest ones up to the limit are moderated; the others show "inPlan": false and are paused until you delete some or upgrade.

Send a key as Authorization: Bearer <key>. The full key is shown only once, when it's created; Jef Bot keeps only a hash. Never put a key in a game client, a browser page or a mobile app: anyone could extract it.

Strikes and the punishment ladder

Each offense is a strike against the user in that app. Strikes count for 24 hours (30 days for high severity). The more active strikes someone has, the further up the ladder their next punishment is: 2 min → 10 min → 1 h → 6 h → 24 h with a final warning → ban. Low-severity offenses start at the bottom, medium at 10 minutes, high at the 24 hour final warning. See rules and punishments.

History

Every automatic action, manual warning, pardon and "watching" note is an event in the app's history, kept for your plan's history period (7, 30 or 90 days). Clean messages are never stored.

AI checks

Spam, scam and keyword checks are free and unlimited. A message that gets past them (and isn't trivial, like "gg") is sent to Jev, which costs one AI check from your monthly allowance. At most a tenth of the monthly allowance can be used in one UTC day, so one busy day can't use up the month. When either runs out, your apps keep running on the free checks until it resets.

Which guide should I follow?

  • You run a Discord server: Discord quickstart. No code needed.
  • You run a game or an app with its own chat: Game chat quickstart. You'll add one HTTP call to your game server.
  • You want an AI coding agent (or a script) to set it up: Setup by AI agents. A person creates one account key; the agent does the rest.
  • You want to react to actions in your own systems (a staff Slack, your own database): Webhooks (Starter and Pro).

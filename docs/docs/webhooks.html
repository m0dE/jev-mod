Webhooks

Get every punishment, manual warning and pardon as a signed HTTP request to your own server, for example to post it in your staff chat or keep your own records. Starter and Pro plans.

Set it up

Set the app's webhook URL in the dashboard, or with an account key:

curl -s -X PATCH https://jef.example.com/v1/apps/$APP_ID \
  -H "Authorization: Bearer $JEF_ACCOUNT_KEY" -H "Content-Type: application/json" \
  -d '{"webhookUrl": "https://game.example.com/hooks/jef"}'

The response's app.webhookSecret (whsec_…) is the key for checking signatures. The URL must be https://, without a username or password, and must point to a public address (not localhost, private or internal networks). Remove the webhook with {"webhookUrl": null}; rotate the secret with POST /v1/apps/{appId}/webhook-secret.

Events

TypeWhen
moderation.actionA message broke the rules and the sender got a strike (a mute or ban). Not sent for "watching" notes, or for messages only deleted because the sender was punished seconds before.
moderation.manualSomeone warned a user by hand (/warn in Discord, the dashboard or the API).
moderation.pardonSomeone removed a user's strikes.

Webhooks work for Discord apps and API apps alike.

Payload

A POST with Content-Type: application/json, User-Agent: JefBot-Webhooks/1 and a Jef-Signature header. The body is always { type, appId, createdAt, data }.

moderation.action

data is the moderation result plus who said what. text is the full message.

Verifying signatures

Each request carries:

Jef-Signature: t=1791460801,v1=5f2b0c…e81a

t is the Unix time in seconds when it was sent. v1 is the hex HMAC-SHA256 of "<t>.<raw body>", keyed with the app's whole webhookSecret string (including whsec_). To verify:

  1. Read the raw request body, before any JSON parsing.
  2. Compute the HMAC of t + "." + body and compare it to v1 in constant time.
  3. Reject it if t is more than 5 minutes from now, so an old request can't be replayed.
// Express. npm install express
import crypto from 'node:crypto';
import express from 'express';

const SECRET = process.env.JEF_WEBHOOK_SECRET; // whsec_…

function verify(header, rawBody, secret, toleranceS = 300) {
  const parts = Object.fromEntries((header ?? '').split(',').map((p) => p.split('=', 2)));
  const t = Number(parts.t);
  if (!Number.isInteger(t) || !parts.v1) return false;
  if (Math.abs(Date.now() / 1000 - t) > toleranceS) return false;
  const expected = crypto.createHmac('sha256', secret).update(`${t}.${rawBody}`).digest('hex');
  const a = Buffer.from(expected);
  const b = Buffer.from(parts.v1);
  return a.length === b.length && crypto.timingSafeEqual(a, b);
}

const app = express();
app.post('/hooks/jef', express.raw({ type: 'application/json' }), (req, res) => {
  const raw = req.body.toString('utf8');
  if (!verify(req.get('Jef-Signature'), raw, SECRET)) return res.status(400).send('bad signature');
  const event = JSON.parse(raw);
  if (event.type === 'moderation.action') {
    console.log(`${event.data.username}: ${event.data.action.label} (${event.data.reason})`);
  }
  res.sendStatus(204);
});
app.listen(8080);
# Flask. pip install flask
import hashlib, hmac, json, os, time
from flask import Flask, request, abort

SECRET = os.environ["JEF_WEBHOOK_SECRET"]  # whsec_…
app = Flask(__name__)

def verify(header, raw_body, secret, tolerance_s=300):
    parts = dict(p.split("=", 1) for p in (header or "").split(",") if "=" in p)
    try:
        t = int(parts["t"])
    except (KeyError, ValueError):
        return False
    if abs(time.time() - t) > tolerance_s or "v1" not in parts:
        return False
    expected = hmac.new(secret.encode(), f"{t}.".encode() + raw_body, hashlib.sha256).hexdigest()
    return hmac.compare_digest(expected, parts["v1"])

@app.post("/hooks/jef")
def jef_hook():
    raw = request.get_data()  # raw bytes, before parsing
    if not verify(request.headers.get("Jef-Signature"), raw, SECRET):
        abort(400)
    event = json.loads(raw)
    if event["type"] == "moderation.action":
        print(event["data"]["username"], event["data"]["action"]["label"])
    return "", 204

Delivery

  • Best effort, no retries. Each event is sent once, with a 5 second timeout. Redirects aren't followed. If your endpoint is down or answers with an error, that event isn't sent again. Your app's history (GET /v1/apps/{appId}/events) is the complete record if you need to catch up.
  • Answer fast with any 2xx; do slow work after responding.
  • Order isn't guaranteed; use createdAt.
  • Paid plans only. If the account moves to Free, webhooks stop being sent (the URL is kept).
  • The host must resolve to public IP addresses when the event is sent (IPv4 addresses written in IPv6 form are checked too); otherwise it's skipped. The connection goes to the exact address that was checked.

Discord quickstart

Add Jef Bot to your Discord server in a couple of minutes. No code needed.

On this page
  • 1. Sign in and create a Discord app
  • 2. Add Jef Bot to your server
  • 3. Put Jef Bot's role above your members
  • 4. Pick a mod log channel
  • What happens when someone breaks the rules
  • Slash commands
  • Settings
  • Unlinking and removing

1. Sign in and create a Discord app

Sign in with Google, then create a new app of kind Discord. Each Discord server needs its own app (the Free plan has one app; Starter 3; Pro 15).

Creating it gives you two ways to connect your server, both valid for 1 hour:

  • an Add to server link, and
  • a link code, used as /jef link code:A1B2C3D4E5F6.

If they expire, get new ones from the app's page (or POST /v1/apps/{appId}/discord/link). Getting a new pair cancels the old one.

2. Add Jef Bot to your server

Open the Add to server link, pick your server and approve. You need the Manage Server permission on that server.

  • Usually Discord sends you straight back to the dashboard and the server is linked automatically. For that, you must be signed in to the Jef Bot dashboard, in the same browser, as the app's owner. If you aren't, linking stops with reason=signed_out or reason=not_owner; sign in and try again (the link still works), or use /jef link.
  • If it isn't (the bot was already in your server, or automatic linking isn't available), run this in any channel of the server, with your code: 
    /jef link code:A1B2C3D4E5F6
    /jef link needs the Manage Server permission. The reply is only visible to you.

Run /jef status to check: it shows which app the server is linked to, the plan, and this month's AI checks and custom rules.

Jef Bot only moderates servers that are linked to an app. Until then it does nothing, and posts one reminder in the server's system channel about how to link it.

The bot asks for these permissions: View Channels, Send Messages, Manage Messages, Embed Links, Read Message History, Moderate Members (for timeouts) and Ban Members. If one is missing, that step is skipped and the others still happen (for example, no timeouts without Moderate Members); failed mutes and bans are noted in the mod log.

3. Put Jef Bot's role above your members

In Server Settings → Roles, drag the Jef Bot role above the roles of the members it should moderate. Discord doesn't let a bot time out or ban anyone whose highest role is above its own; the mod log then says "cannot mute this member".

4. Pick a mod log channel

Run /modlog channel:#staff-log (needs Manage Server), or set it in the dashboard. Make sure Jef Bot can see and post in that channel. Every action, every "watching" note and every rule change is posted there, so your team can review what Jef Bot did.

That's it. Optionally, add your own rules with /rule add.

What happens when someone breaks the rules

  1. The message is deleted.
  2. The member gets a DM with the punishment and the reason.
  3. They're timed out for the punishment's length, or banned at the top of the ladder (a ban also deletes their messages from the last hour).
  4. A short notice appears in the channel ("your message was removed: …") and deletes itself after 15 seconds.
  5. The details go to your mod log: who, where, category and severity, active offenses, whether the DM arrived, and the message text.

Earlier copies of a spam wave and the rest of a scam run are deleted too. Edited messages are checked again, so nobody can post something clean and edit it afterwards.

Never moderated: bots, the server owner, anyone with the Manage Messages permission, and any roles and channels you exempt in settings.

See rules and punishments for what's moderated and the full ladder.

Slash commands

Replies are only visible to the person who ran the command. Server admins can change who may use each command in Server Settings → Integrations → Jef Bot.

CommandWhat it doesDefault permission
/strikes userA member's active offenses, when each expires, and what their next offense would getModerate Members
/warn user reason [severity]Punish a member by hand, on the same ladder. Severity defaults to medium. If the result would be a ban, you also need Ban Members.Moderate Members
/pardon user [count]Remove a member's most recent offenses (all of them if no count)Moderate Members
/rule add text [severity]Add a rule of your own, in plain words (up to 300 characters). Severity defaults to low.Manage Server
/rule list, /rule remove idShow or remove your rulesManage Server
/modlog channelChoose where actions are loggedManage Server
/jef link codeLink this server to a Jef Bot appManage Server
/jef statusWhich app this server is linked to, its plan and this month's usageManage Server

Custom rules need the AI, and each plan has a limit per app (3, 15 or 50). Rules, strikes and history are shared with the dashboard and the API: a /warn shows up in the app's history, and a rule added in the dashboard applies in Discord.

Settings

Each Discord app has three settings, in the dashboard or through PATCH /v1/apps/{appId}:

SettingWhat
modLogChannelIdThe mod log channel ID (same as /modlog).
ignoredChannelIdsChannel IDs Jef Bot never moderates (up to 100).
exemptRoleIdsRole IDs whose members are never moderated (up to 100).
 
curl -s -X PATCH https://jef.example.com/v1/apps/$APP_ID \
  -H "Authorization: Bearer $JEF_ACCOUNT_KEY" \
  -H "Content-Type: application/json" \
  -d '{"settings": {"modLogChannelId": "1234567890123456789", "exemptRoleIds": ["2345678901234567890"]}}'

To copy IDs in Discord, turn on User Settings → Advanced → Developer Mode, then right-click a channel or role and choose Copy ID. Setting a value to null clears it.

On Starter and Pro you can also send every action to your own systems with a webhook.

Unlinking and removing

  • Move the server to another app on the same account: run /jef link with the other app's code. A server already linked to an app on a different account must be unlinked by that account first.
  • Unlink from the dashboard (or DELETE /v1/apps/{appId}/discord): the bot stays in the server but stops moderating.
  • Kick Jef Bot from the server: the app is unlinked and the server's strikes and history are deleted. The app, its rules and settings stay, so you can link it again. If the bot was removed while Jef Bot was offline, this happens when it next starts.
  • Over your plan's app count (after a downgrade): only your oldest apps up to the limit are moderated. A server linked to a newer app is ignored until you delete an app or upgrade.
  • Delete the app: its rules, strikes, history and keys are deleted.
